ENUNCIADO:

Desarrolla una aplicación web para gestionar los vehículos de varios talleres mecánicos.
Un taller puede tener varios vehículos, pero cada vehículo pertenece a un único taller.

La aplicación deberá ofrecer una API REST y una interfaz web con Thymeleaf.
Ambas utilizarán los mismos DAO, sin duplicar consultas SQL.

1. BASE DE DATOS

Utiliza la base de datos gestion_talleres, con dos tablas:

- talleres: nombre (VARCHAR(100), PK), ciudad (VARCHAR(100)).
- vehiculos: matricula (VARCHAR(10), PK), marca (VARCHAR(100)), modelo (VARCHAR(100)), precio (DECIMAL(10,2)), taller (VARCHAR(100), FK a talleres.nombre).

Debe haber inicialmente dos talleres y al menos tres vehículos.
El script SQL se proporciona al final del enunciado.

2. API REST

Todas las rutas REST comienzan por /api y devuelven JSON.
Los POST y PUT reciben sus datos en el cuerpo de la petición.

GET    /api/talleres                    Lista todos los talleres.
GET    /api/vehiculos                   Lista todos los vehículos.
POST   /api/vehiculos                   Inserta un vehículo.
PUT    /api/vehiculos/{matricula}       Modifica marca, modelo y precio de un vehículo.
DELETE /api/vehiculos/{matricula}       Elimina un vehículo.

3. INTERFAZ THYMELEAF

talleres.html: listado de talleres.

detalle.html: información del taller seleccionado y sus vehículos.

vehiculos.html: listado y formulario para añadir vehículos.

editar.html: formulario de modificación de vehículos.

Después de guardar, actualizar o eliminar, se vuelve a /vehiculos.

============================================================
SCRIPT SQL
============================================================

DROP DATABASE IF EXISTS gestion_talleres;

CREATE DATABASE gestion_talleres;

USE gestion_talleres;

CREATE TABLE talleres (
    nombre VARCHAR(100) PRIMARY KEY,
    ciudad VARCHAR(100)
);

CREATE TABLE vehiculos (
    matricula VARCHAR(10) PRIMARY KEY,
    marca VARCHAR(100),
    modelo VARCHAR(100),
    precio DECIMAL(10,2),
    taller VARCHAR(100),
    FOREIGN KEY (taller) REFERENCES talleres(nombre)
);
